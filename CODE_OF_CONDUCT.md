# Código de conduta

Este projeto segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/). Em resumo:

- Trate todo mundo com respeito, em issues, pull requests e onde mais o projeto aparecer.
- Críticas são sobre o código, nunca sobre a pessoa. Seja gentil com quem está contribuindo pela primeira vez.
- Não são aceitos assédio, ofensas, discriminação de qualquer tipo, nem publicar informações privadas de alguém.

O mantenedor pode editar ou remover comentários, issues e PRs que não sigam essas regras, e bloquear quem insistir nesse comportamento.

Para reportar um problema, fale com o mantenedor [@erickmsms](https://github.com/erickmsms) pelo GitHub. As denúncias são tratadas com sigilo.
